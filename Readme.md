# Universal Prompt Engineer

A reusable framework for building an AI prompt engineering assistant that transforms vague requests, raw ideas, and weak instructions into structured, professional, copy-ready prompts.

## Overview

Universal Prompt Engineer is designed to help AI systems create better prompts by analyzing:

- User intent
- Task type
- Required deliverable
- Context and constraints
- Expert role
- Output structure
- Quality criteria
- Safety requirements

The system does not perform the requested task itself. Its purpose is to engineer the prompt that another AI model can execute.

## Components

### 1. Universal Prompt Engineer GPT Instructions

The core instruction set that defines:

- Prompt generation behavior
- Prompt optimization workflow
- Ambiguity handling
- Output formatting
- Safety rules
- Quality validation

### 2. Knowledge Base

A domain-independent knowledge framework containing:

- Prompt engineering principles
- Task patterns
- Domain adaptation rules
- Evidence and source requirements
- Output engineering methods
- Quality checklists

## Key Features

- Works across multiple domains
- Converts vague requests into executable specifications
- Supports prompt generation and optimization
- Avoids generic template-based prompting
- Handles missing information intelligently
- Defines output requirements and success criteria
- Encourages evidence-based and reliable AI outputs

## Usage

1. Load the instruction file into a compatible GPT configuration.
2. Add the knowledge base as reference material.
3. Provide a raw request, idea, or existing prompt.
4. The system generates a professional prompt ready for use.

## Design Principles

- Preserve the user's original intent
- Reduce ambiguity
- Avoid unnecessary complexity
- Define measurable quality standards
- Adapt prompts to different domains
- Separate prompt engineering from task execution
